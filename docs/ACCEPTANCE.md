# 康复训练助手 — 真机验收清单

按顺序逐项验收。环境:安卓真机(Android 8.0+)安装 `app-debug.apk`;康复靴掌控板固件按 `docs/PROTOCOL.md` 实现并可联网。

## 一、平台准备

- [ ] 注册/登录 https://iot.dfrobot.com.cn(DFRobot 统一账号)
- [ ] 工作间 → 「添加新的设备」创建 1 个设备,记录其 Topic
- [ ] 显示账号级 `Iot_id` / `Iot_pwd`(点眼睛图标)
- [ ] 在掌控板固件中填入上述参数,确认设备端能连上平台(固件日志无报错)

## 二、设置页

- [ ] 打开 App → 「设置」,填写 服务器(iot.dfrobot.com.cn)/ 端口(1883)/ Iot_id / Iot_pwd / 设备 Topic
- [ ] 点「测试连接」→ 提示"连接成功"
- [ ] 故意填错 Iot_pwd → 测试连接 → 提示"连接被拒绝,请检查 Iot_id / Iot_pwd 与服务器"
- [ ] 飞行模式 → 测试连接 → 提示"网络不可达…"
- [ ] 填体重 70、百分比 25/50/75 → 「保存」→ 提示"已保存"
- [ ] 填体重 500 → 保存 → 显示校验错误且不保存
- [ ] 打开「启用后台连接」→ 提示服务已启动;系统通知栏出现常驻通知「已连接 · Topic」
- [ ] Android 13+ 首次打开开关会请求通知权限;拒绝后 App 不崩溃(通知不显示属预期)

## 三、监测页(实时监测)

- [ ] 监测页显示"已连接"(绿色圆点)
- [ ] 脚踩康复靴:大数字实时显示负重 kg,数字随压力变化
- [ ] 阈值进度条出现四段着色与当前值指针;踩过 25%/50%/75% 时指针进入对应区段
- [ ] 近 30 秒趋势曲线随踩踏滚动,最新点有圆点标记
- [ ] 固件按协议在对应阈值触发语音提醒(固件侧验收)
- [ ] 断开 WiFi(飞行模式):顶部变为"已断开,点按重连"(红点),常驻通知同步变化
- [ ] 恢复网络:10 秒内自动重连,回到"已连接",数据恢复流动
- [ ] 手动点连接状态条 → 主动重连

## 四、训练会话

- [ ] 点「开始训练」→ 出现 暂停/结束 按钮与统计行(时长走动、平均/峰值实时更新)
- [ ] 踩踏若干次,统计随数据更新
- [ ] 点「暂停」→ 时长冻结;点「继续」→ 继续累计
- [ ] 点「结束」→ 提示"训练完成,已保存"
- [ ] 未开始训练时无结束按钮(不存在空会话保存)

## 五、历史页

- [ ] 历史页显示刚结束的会话:日期时间、时长、平均/峰值
- [ ] 点记录 → 详情弹窗字段正确
- [ ] 长按/点删除 → 确认弹窗 → 确认后消失并提示"已删除"
- [ ] 全部删除后显示空状态引导文案
- [ ] 杀掉 App 进程重开 → 历史仍在(Room 持久化)

## 六、后台与息屏

- [ ] 会话进行中按 Home 键退后台 → 通知栏仍显示连接状态
- [ ] 息屏 1 分钟再点亮 → App 内数据仍实时(前台服务保活)
- [ ] 训练中 App 退后台不中断会话统计(统计在 ViewModel,回前台继续)

## 七、健壮性

- [ ] 固件发送乱帧(如 "garbage")→ App 底部"数据帧无效:N"计数增加,不崩溃
- [ ] 固件发送负数压力 → 被丢弃,不显示负值
- [ ] 未填配置时点监测页状态条 → 提示"请先在「设置」页填写平台连接信息"
- [ ] 关闭「启用后台连接」→ 通知消失,连接断开

## 八、回归说明

- 修改任何连接参数并保存后,若连接已启用,应重启一次连接(开关关→开)使新参数生效。
- 平台「重新生成」凭据会作废旧值,需同步更新 App 与固件。
