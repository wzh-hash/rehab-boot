# 康复训练助手 — 真机验收清单(v2,对齐 Mind+ 固件)

环境:安卓真机安装 `app-debug.apk`;掌控板已烧录提供的 Mind+ 固件并通电联网。

## 一、平台与设备准备

- [ ] 掌控板通电:OLED 依次显示"WiFi连接成功"→"MQTT连接成功"
- [ ] 设备按键 P14/P15 可调体重(OLED 第 2 行显示,默认 50kg)
- [ ] App 设置页填写(与固件一致):iot_id=`TyFA89yHR`、iot_pwd=`5318397328084412`、Topic=`wIOqDXyDg`(服务器/端口默认值即可)

## 二、连接

- [ ] 「测试连接」→ 提示"连接成功"
- [ ] 打开「启用后台连接」→ 通知栏出现"已连接 · wIOqDXyDg"
- [ ] 监测页顶部"已连接"(绿点)
- [ ] 等待设备 `hello` → 监测页出现"设备已上线"徽标
- [ ] 重启掌控板 → 徽标短暂消失(断开)后重新点亮(设备重连后再次发 hello)
- [ ] 飞行模式 → 顶部"已断开,点按重连";恢复网络 → 自动重连

## 三、远程训练(核心闭环)

1. [ ] 点「语音测试」→ 设备播报"你好患者"
2. [ ] 点「25% 训练」→ 设备语音"开始训练";App 显示"设备训练中…",四个比例按钮变灰禁用
3. [ ] 踩踏康复靴,压力超过 体重×25% → 设备语音"已达到训练的重量"+ LED 闪烁;App 时间线出现"已达到目标重量"
4. [ ] 一次重复完成 → App 时间线出现"完成一次重复",进度显示"第 1/3 次完成"
5. [ ] 重复 2~3 次(每次踩压达标)→ 进度到"第 3/3 次完成"
6. [ ] 第 3 次完成后:App 提示"训练完成,已记录",按钮恢复可点
7. [ ] 训练中点其它比例按钮 → 无反应(禁用),无重复指令下发

## 四、历史页

- [ ] 刚结束的训练出现在列表:日期、目标比例 25%、完成 3/3 次、"已完成"
- [ ] 点击记录 → 详情弹窗字段正确
- [ ] 删除记录 → 确认后移除并提示"已删除"

## 五、超时与异常

- [ ] 设备断电后发令训练 → 10 分钟内无事件 → App 提示"训练超时,已记录(未完成)",历史页该记录显示"未完成"
- [ ] 设备端手动向该 topic 发乱码(如通过平台控制台"发送消息")→ App 底部"数据帧无效:N"计数增加,不崩溃
- [ ] 未填配置时点连接状态条 → 提示"请先在「设置」页填写平台连接信息"

## 六、后台与息屏

- [ ] 训练进行中按 Home 退后台 → 通知栏仍显示连接状态
- [ ] 息屏 1 分钟再点亮 → 事件仍实时接收(前台服务保活)
- [ ] 关闭「启用后台连接」→ 通知消失,连接断开

## 七、注意事项

- 修改连接参数并保存后,若连接已启用,需关→开一次开关使新参数生效
- 训练中设备为阻塞循环,App 发令会在当前训练结束后才被处理——App 已通过禁用按钮避免
- 换平台账号需同步修改掌控板固件(Mind+ 项目中的 Iot_id/Iot_pwd/Topic)

## 九、v3 新增验收项

- [ ] **升级不闪退**:从 v2(或 v1)直接安装 v3 覆盖升级 → 打开历史页不崩溃,历史数据保留(v1 旧记录会因结构不兼容被清除,属预期)
- [ ] **计步**:训练开始后走动若干步 → 监测页进度卡"步数"随走动增长;会话结束 → 历史页记录显示步数
- [ ] **计步不可用**:无计步传感器的设备(或拒绝传感器权限)→ 进度卡不显示步数,训练功能正常
- [ ] **传感器权限**:Android 10+ 首次点训练比例时弹出"身体活动"权限请求;拒绝后仅计步不可用
- [ ] **界面美化**:监测页渐变比例按钮(25% 最浅→100% 最深)、单条状态栏、训练进度卡高亮条与事件时间线圆点样式、语音测试为文字按钮
- [ ] **文案**:界面不再出现"点按/已记录/⚠ emoji"等旧文案(如"连接已断开,点击重试")
